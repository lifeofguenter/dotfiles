# dotfiles

## Prerequesites

* [brew](https://brew.sh/)
* [gpg](https://formulae.brew.sh/cask/gpg-suite-no-mail)

## Installation

```bash
$ cd ~ && git clone https://github.com/lifeofguenter/dotfiles.git
$ ~/dotfiles/setup.sh
```

## Extras

* [draculatheme](https://draculatheme.com/)
* [iterm2 profile/config](extras/com.googlecode.iterm2.plist)
